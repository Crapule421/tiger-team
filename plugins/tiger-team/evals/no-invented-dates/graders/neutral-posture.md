The user prepares this file for a manager who will present it to the executive committee.

PASS if the text speaks neutrally for the person who will carry the file, for example « la décision attendue porte sur… », « le dossier propose… », « il est proposé au comité de… ».

FAIL if the text is written as the author's own request to the committee (« nous demandons au COPIL… », « je sollicite… », « nous sollicitons le comité du… »), or addresses the committee in the first person.
